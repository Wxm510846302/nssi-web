# NSSI Clinical Web Brief

基于 `/Users/xuemingwang/Desktop/非自杀性自伤的临床诊治.docx` 制作的动态网页演示。

## 打开方式

直接用浏览器打开：

```bash
open /Users/xuemingwang/Desktop/KKHC/nssi-web/index.html
```

或者启动一个本地静态服务器：

```bash
cd /Users/xuemingwang/Desktop/KKHC/nssi-web
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。
